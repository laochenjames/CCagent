# CCagent · 管理者任务分诊台 (Task Triage Studio)

> **定位**：非 ToDoList，而是专为管理者设计的「**精力分诊台**」。  
> 每天花 2 分钟把杂乱的任务倾倒进来，利用高管穿透逻辑剥离假火警、坚决授权、砍掉内耗，拿回一份清晰的执行与排期单。

---

## 🌟 核心功能清单

1. **时态多维度输入**：
   - 自动识别并归纳：`今日已完成(Done)`、`今日顺延(Rollover)`、`明日待办(Tomorrow)`、`远期设想(Future)`。
   - 自带脱敏合规提醒（防止输入商业机密/敏感薪酬数据）。
2. **艾森豪威尔四象限 + 备选区（四格 + 一池）**：
   - 🔴 **今天必做 (Q1)**：重要且紧急 · 核心单向门交付 / 线上故障 / 关键违约危机。
   - 🔵 **深度排期 (Q2)**：重要不紧急 · 团队建设 / 流程基建 / 长期战略（预留整块黄金专注时间）。
   - 🟡 **坚决授权 (Q3)**：紧急不重要 · 琐碎审批 / 下属反向委派 / 临时催促（交代边界与抓手）。
   - ⚪ **建议放弃/延后 (Q4)**：不重要不紧急 · 伪需求 / 过早优化 / 摸鱼内耗（礼貌得体推脱）。
   - 📦 **【待决备选区】(Candidate Pool)**：收纳定义模糊、未想好、或缺少截止日期的事项，提供反问促使管理者厘清。
3. **流畅的人机协作与手动调节**：
   - **全自由拖拽 (HTML5 Drag & Drop)**：任意卡片可在 4 个象限与备选区之间随心拖拽流转。
   - **原位微调与快速增删**：支持原位修改文字、一键打勾归档、手动快速加单。
4. **双视图无缝切换**：
   - 🗂️ **四象限看板视图**：鸟瞰全局，洞察精力分布结构。
   - 📜 **优先级线性动线序列**：按 09:00-11:30 晨间攻坚 Q1/Q2、16:30 统一批处理 Q3 授权的节奏智能排布。
5. **战报长图截图卡片**：
   - 一键生成高管精力复盘卡片（深色现代高管视觉风格，带实时数据指标、核心战场与释放精力亮点）。
   - 原生 HTML5 Canvas 导出超高清 PNG 图片，100% 离线可用，方便朋友圈、社群打卡与 IP 裂变。
6. **多端平台适配包 (前店后厂引流闭环)**：
   - 配套 **扣子 (Coze)** 与 **腾讯元器** 专用提示词模板，包含向本 Web 工作台引流的钩子文案。
   - 内置 **首批 10 个高频管理事件库 (V2 规则底座)**，含下属请示、跨部门扯皮、老板深夜想法等现成处置话术。

## 🚀 快速上手与运行

本项目采用轻量无依赖设计（Zero-dependency Vanilla Web），开箱即用：

### 方式 1：直接双击运行
直接在文件资源管理器中双击打开 `index.html` 即可在浏览器中使用全部功能！

### 方式 2：使用本地服务（已集成 Google Gemini API 转发，推荐）
```bash
# 进入目录运行服务端（默认端口 8099）
python server.py
```
浏览器访问：`http://127.0.0.1:8099`

在网页右上角点击 **「⚙️ API 配置」**：
1. 填入你的 Google Gemini API Key（以 `AIzaSy` 开头）。
2. 可选模型（默认推荐毫秒级响应的 `gemini-2.0-flash`，也支持 `gemini-1.5-flash`）。
3. 支持点击 **「🔍 测试连通性」** 验证 API Key 状态。
4. 也可直接写入 `E:\Doc\Python_daye\CCagent\.env` 文件的 `GEMINI_API_KEY=` 字段。
