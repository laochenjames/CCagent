# 评分校准说明

本目录用于校准 `score.py` 与 `engine.py` 中的经验权重和阈值。

- `personas.json` 中的 8 条为**合成用例**，其 `expected` 仅代表设计预期，不能当作真实统计依据。
- 补充真实过往项目时：只填写项目**开始时**已知的信息，在 `outcome` 字段记录事后真实结果（成功 / 一般 / 失败），再用 `python tools/calibrate.py` 对比模型输出与真实结果，最后调整 `score.py` / `engine.py` 顶部的常量。
- 设计取舍："这组不适用于我"开关允许用户手动排除某组，但该机制也可能被用来回避弱项（例如把变现困难标成不适用）；因此报告中会明确列出已排除的维度。
