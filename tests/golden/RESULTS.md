# 手动验收清单（v2.3.1）

请在启动本地服务后逐条手动验收并勾选：

- [ ] 1. 完整走一遍：输入一句话 → 开始体检 → 填几项 → 点"查看详细分析"，页面不报错且渲染分析。
- [ ] 2. 点"补充抽取"，页面不报错且显示新版本结果。
- [ ] 3. 在数字输入框填值后清空并失焦：评分与置信度回到未填状态。
- [ ] 4. 用开发者工具向 `/fields` 提交 `paid_evidence="xxx"`：返回 400。
- [ ] 5. 触发红线（借钱投入）：不显示置信度百分比，显示"由规则直接判定（红线）"。
- [ ] 6. 对"变现与需求"点"这组不适用于我"：仪表盘写"评分未包含：变现与需求"；当该因子在计入时会评为低，附带"若计入将评为低"。
- [ ] 7. 工资照发、现金 2 万、月支出 1 万、不填"仍有收入"：风险条出现黄色提示、没有红线、评估词不是"不建议投入"。
- [ ] 8. 超过 2000 字的输入被拒绝并提示。
- [ ] 9. 触发红线后，打开历史会话列表：该会话显示"偏低 · 红线"。
- [ ] 10. 红线会话的仪表盘只显示"由规则直接判定（红线）"，没有"置信度"字样。
- [ ] 11. 红线会话下载 HTML 和 Markdown 报告：摘要里没有置信度百分比。
- [ ] 12. 对"变现与需求"点"这组不适用于我"（该因子本应评低）后下载 Markdown 报告：含"评分未包含"和"若计入将评为低"。
