# 访谈话术库与参数转换表（咨询师主导模式）

用法：用左列的问法提问，把客户的原话记下来，按"转换规则"换成参数，再用"回译确认"念给客户听，客户说"对"才算确认。**原话必须保留**，方便事后复盘你的转换是否带入了自己的判断。

| 想拿到的参数 | 生活化问法 | 转换规则 | 回译确认话术 |
|---|---|---|---|
| 评估的决策 | "你现在纠结的具体是哪件事？要不要……？" | 写成"要不要做 X"，而非"X 项目" | "你要决定的是：要不要……，对吗？" |
| 项目目的 | "你做这件事，最想得到什么？赚钱、学东西，还是换方向？" | 取首要一项，次要的另记 | "你最看重的是……，赚钱是顺带的/主要的，对吗？" |
| 直接成本 | "这件事需要花钱吗？大概花多少？" | 按用户上限记；说"不用花钱"记 0 | "前期基本不花钱/最多花……，对吗？" |
| 无风险现金 | "不算投资账户，你银行卡、微信、支付宝一共有多少钱？" | 只计会亏的以外的资产 | "除投资账户外，你手上大约有……，够撑……个月，对吗？" |
| 月支出 | "一个月正常花销大概多少？" | 取区间上限 | "一个月大约……，对吗？" |
| 周投入小时 | "上个月你实际每周花了几个小时在这上面？" | 以实际为准；"没做"记 0 | "上个月实际每周约……小时，打算以后每周……小时，对吗？" |
| 连续性 | "过去一年里，大概有几周是真的在做的？" | 周数 ÷ 52 | "一年里大约有……周在做，也就是……成时间，对吗？" |
| 起始月 | "你觉得大概第几个月，第一笔钱会进来？" | 用户原话；校准时 ×2 | "你觉得第……个月开始有收入，我会按更保守的……个月估，可以吗？" |
| 场景金额 | "如果做得还行，每个月大概多赚多少？" | 追问到"单价 × 单量"；说"没概念"则不填，走反推模式 | "大概是卖……元的服务，每月成交……单，对吗？" |
| 场景概率 | "十次这样的尝试，你觉得有几次能做成？" | 次数 ÷ 10；无先例的按校准打折 | "你觉得十次里有……次，我会按……次估，行吗？" |
| 先例 | "有没有人用同样的方式做成过？你认识吗？" | 无则记"需求未验证" | "目前没找到做成的先例，所以需求还要先验证，对吗？" |
| 最低时薪 | "如果有人付钱请你做，每小时低于多少你会觉得不值？" | 答"都行"记未设定，用参照值 | "你没有明确底线，我先用……元/小时做参照，可以吗？" |
| 止损 | "做多久没结果你会停？到时候真的会停吗？" | 取月数；追问"凭什么判断没结果" | "做到第……个月，如果还没……，你会停，对吗？" |
| 基线 | "不改变现状，你觉得三年后每月收入大概怎样？最好/一般/最差各是多少？" | 三个值，与近期实际对照 | "你预期三年后每月……，目前实际是……，差距来自……，对吗？" |

## 注意事项
- 客户说"没概念"的地方，不替他填数；走反推模式，让他判断"要达到多少才值得"。
- 同一问题最多问 2 次，第二次换更生活化的说法，仍答不出就记"未知"。
- 客户明确说"别问这个"的话题，先照办；确实绕不过去时，说明原因再问一次。
- 批判针对数据和假设，不评价客户的性格或动机。
