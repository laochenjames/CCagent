CCagent Privacy Policy / 隐私政策

Effective & Last Updated: 2026-11-28 · Product: CCagent Chrome Extension ("CCagent 智囊团侧边栏") & Web Service (https://ccagent.mycici.top)

English Version 中文版本

1. Overview

This Privacy Policy explains in detail how the CCagent Chrome Extension and its hosted web service (https://ccagent.mycici.top) collect, process, store, and share user data. We are committed to strict data minimization and full transparency.

2. Data We Collect & Access

CCagent only accesses data when you explicitly trigger an action (clicking the injected CC button on a post on X/Twitter, using the right-click context menu, pressing Alt+C, or manually typing into the side panel). We do not passively track your browsing history, scrape pages in the background, or collect personal identity information (such as your name, email, or account credentials).

Data Category Specific Data When Collected
User-Submitted Text Selected webpage text or the text of a specific X (Twitter) post you choose to analyze, plus optional follow-up notes you type. Only when you click CC, use the context menu, press Alt+C, or submit text in the side panel.
Local Extension Settings (BYOK) Your preferred AI provider, model name, custom API base URL, and optional personal API key (e.g., Google Gemini, xAI Grok, DeepSeek). Only if you voluntarily enter and save them in the extension settings.
Technical / Rate-Limit Data IP address and request timestamps when using the free hosted tier without your own API key. Automatically processed by the server solely to enforce free daily usage quotas and prevent abuse.

3. How We Use & Process User Data

  • Mental-Model Analysis & Auto-Routing: Text you explicitly submit is sent over encrypted HTTPS to https://ccagent.mycici.top to (a) determine the most suitable Charlie Munger mental-model agent via /api/route, and (b) generate the structured analysis report displayed in your side panel.
  • BYOK (Bring Your Own Key) Forwarding: If you configure your own API key, the extension passes your key over HTTPS in the request payload to our backend proxy, which forwards the request directly to your selected AI model provider to generate the response.
  • Quota & Service Reliability: Technical request metadata (IP address) is used solely to enforce free-tier rate limits and protect the service from abuse.
  • No Secondary Use: We never use your data for advertising, behavioral profiling, marketing, creditworthiness evaluation, or training AI models.

4. How We Store & Retain User Data

  • Local Browser Storage: Your extension preferences, selected agent, and optional BYOK API key are stored locally in your browser using chrome.storage.local and in-memory session variables. They remain on your device until you clear them or uninstall the extension.
  • Server-Side Processing (No Permanent Storage of Prompts or Keys):
    • Your optional BYOK API key is never written to disk, logged, or persisted on CCagent servers; it exists only in volatile memory for the duration of the single HTTP request.
    • Submitted text and generated analyses are processed in memory and returned directly to your browser. CCagent does not build user accounts or permanently archive your submitted tweets/texts on our servers.
    • Rate-limiting counters (hashed/IP-based quota counts) are retained only as long as necessary to enforce daily/periodic free quotas and are automatically cleared or rotated.

5. Third Parties With Whom User Data Is Shared

We do not sell, rent, or trade user data to any third party. User-submitted text is shared only with the following infrastructure and AI model providers strictly to fulfill your analysis request:

  • CCagent Hosted Backend (https://ccagent.mycici.top): Receives your explicitly submitted text over HTTPS to perform routing and proxy requests to the AI provider.
  • AI Model Providers (Third-Party Processors): Depending on the active model or your BYOK configuration, the text you submit for analysis is transmitted to one of the following third-party AI APIs to generate the response:
    • Google LLC (Gemini API) — default hosted model provider and optional BYOK provider (Google Gemini API Terms).
    • xAI Corp. (Grok API) — only if selected by you via BYOK (xAI Privacy Policy).
    • DeepSeek (DeepSeek API) — only if selected by you via BYOK (DeepSeek Privacy Policy).
    • User-Configured Custom Endpoint — only if you explicitly enter a custom OpenAI-compatible API Base URL in settings.

6. Chrome Web Store Limited Use Compliance

CCagent's use and transfer of information received from Google APIs and browser permissions strictly adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. All data access is strictly limited to providing the user-facing mental-model analysis feature described in the store listing.

7. User Control & Data Deletion

  • You can clear your saved API key and local preferences at any time inside the extension settings panel, or by uninstalling the CCagent extension (which automatically removes all chrome.storage.local data).
  • Because CCagent does not require user accounts or permanently store your submitted text on our servers, no server-side account deletion is needed. If you have any data deletion inquiry, please contact us below.

8. Contact Us

If you have questions about this Privacy Policy or how your data is handled, please open an issue on our open-source repository: https://github.com/laochenjames/CCagent/issues.

1. 概述

本隐私政策详细说明 CCagent Chrome 浏览器扩展（“CCagent 智囊团侧边栏”）及其托管服务（https://ccagent.mycici.top）如何收集、处理、存储与共享用户数据。我们坚持数据最小化与完全透明原则，所有代码均已开源。

2. 我们收集和访问的数据

CCagent 仅在你主动触发操作时（点击 X/Twitter 推文上的 CC 按钮、点击右键菜单、按下 Alt+C 快捷键，或在侧边栏手动输入）才会读取对应内容。本扩展不会在后台监控你的浏览记录、不会自动抓取未选中的网页，也不收集姓名、邮箱或账号密码等个人身份信息。

  • 用户主动提交的文本：你主动选中或点击 CC 发送的网页文本 / X (Twitter) 推文内容，以及你在侧边栏中主动输入的补充内容。
  • 本地扩展设置（BYOK）：你自愿在设置中填写的 AI 服务商、模型名称、自定义 API Base URL 以及个人 API Key（如 Google Gemini、xAI Grok、DeepSeek）。
  • 技术与限流数据：当你使用免费托管额度（未填写个人 API Key）时，服务器会临时处理请求 IP 地址与时间戳，仅用于防止滥用与统计免费调用配额。

3. 我们如何使用和处理数据

  • 智能路由与思维模型分析：你主动提交的文本会通过 HTTPS 加密传输至 https://ccagent.mycici.top，用于（a）通过 /api/route 匹配最合适的查理·芒格思维模型，以及（b）生成结构化的深度分析报告并展示在侧边栏中。
  • BYOK（自带密钥）转发：若你填写了个人 API Key，扩展会在你发起分析时通过 HTTPS 将密钥随请求转发至后端代理，仅用于代你向指定的 AI 模型服务商请求生成结果。
  • 配额与防滥用：技术请求信息（如 IP）仅用于免费额度限流与保障服务稳定。
  • 绝无二次用途：我们绝不将你的任何数据用于广告投放、用户画像、营销推广、信用评估或训练 AI 模型。

4. 数据的存储与保留

  • 浏览器本地存储：你的扩展偏好设置、当前模型选择与可选的个人 API Key 仅存储在你的本地浏览器 chrome.storage.local 与会话内存中，直到你手动清除或卸载扩展。
  • 服务端处理（不持久化存储文本与密钥）：
    • 你的个人 API Key 绝不会写入 CCagent 服务器磁盘、数据库或日志，仅在单次 HTTP 请求的内存中短暂使用并立即释放。
    • 你提交的文本和生成的分析结果仅在内存中实时处理并返回浏览器，CCagent 不建立用户账号，也不在服务器上永久归档你的推文或分析内容。
    • 免费额度限流计数仅在配额周期内临时保留，过期自动清理。

5. 与哪些第三方共享数据

我们绝不向任何第三方出售、出租或交易用户数据。你主动提交的分析文本仅会为了完成本次分析请求，传输给以下必要的技术与 AI 模型服务商：

  • CCagent 托管后端（https://ccagent.mycici.top）：通过 HTTPS 接收你主动提交的文本，完成模型路由与请求转发。
  • AI 模型提供商（第三方处理方）：根据当前使用的模型或你的 BYOK 配置，你提交的文本会被发送至以下对应 AI 服务商以生成分析内容：
    • Google LLC（Gemini API）：默认托管模型提供商，也支持 BYOK。
    • xAI Corp.（Grok API）：仅在你于 BYOK 设置中主动选择时使用。
    • DeepSeek（DeepSeek API）：仅在你于 BYOK 设置中主动选择时使用。
    • 用户自定义端点：仅在你于设置中主动填写自定义 OpenAI 兼容 API Base URL 时使用。

6. 有限使用承诺（Limited Use）

CCagent 对所有浏览器权限与用户数据的访问和传输严格遵守 Chrome 应用商店用户数据政策（包括有限使用要求），仅用于提供面向用户的思维模型分析核心功能。

7. 用户控制与数据删除

你可以随时在扩展设置面板中清除保存的 API Key 与偏好设置，或直接卸载本扩展以彻底删除浏览器本地的 chrome.storage.local 数据。由于服务端不存储你的个人账号及历史文本，无需额外注销账号。

8. 联系我们

如有任何隐私相关疑问或数据删除请求，请通过 GitHub Issues 联系我们：https://github.com/laochenjames/CCagent/issues。
