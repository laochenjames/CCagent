CCagent 隐私政策 / Privacy Policy

Last updated: 2026-11-26 · Open Source: github.com/laochenjames/CCagent

1. 我们处理哪些数据 / Data We Process

  • 仅处理你主动发送的文本：只有当你主动点击推文上的 CC 按钮、右键菜单或按下 Alt+C 时，选中的文本才会被发送到 CCagent 侧边栏进行分析。本扩展不会在后台自动抓取或监控你的浏览记录。
  • API Key 仅存储在你的本地浏览器：如果你在扩展设置中填写了自己的 xAI Grok / Google Gemini / DeepSeek API Key，该密钥仅保存在本地 chrome.storage.local 与浏览器内存中，并在你主动发起分析请求时通过 HTTPS 转发至对应的模型服务商，不会写入或持久化到 CCagent 服务器。

2. 数据用途与第三方共享 / Data Usage & Sharing

  • 你主动提交的分析文本仅用于生成本次思维模型分析结果。
  • 我们不会将你的任何数据用于广告投放、用户画像或出售给第三方。

3. 开源与透明 / Open Source

CCagent 的浏览器扩展与后端代码均已完整开源（MIT License），任何人均可审查代码以确认上述隐私承诺。

4. 联系我们 / Contact

如有任何隐私相关问题，请通过 GitHub Issues 联系：https://github.com/laochenjames/CCagent/issues
